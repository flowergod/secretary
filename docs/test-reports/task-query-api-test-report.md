## 已知问题

### 问题 1: 日期范围查询不正确

**问题描述**: `due_date_from` 和 `due_date_to` 参数没有正确实现范围过滤

**当前代码**:
```typescript
if (filter?.due_date_from) {
  conditions.push({
    field_name: '截止日期',
    operator: 'isNot',
    value: [''],
  });
}
```

**修复建议**: 使用飞书支持的范围查询操作符：
```typescript
if (filter?.due_date_from && filter?.due_date_to) {
  conditions.push({
    field_name: '截止日期',
    operator: 'isGreaterEqual',
    value: [filter.due_date_from],
  });
  conditions.push({
    field_name: '截止日期',
    operator: 'isLessEqual',
    value: [filter.due_date_to],
  });
}
```

### 问题 2: 分页参数未生效

**问题描述**: `page_size` 设置后仍然返回所有数据

**可能原因**: 飞书 Bitable API 的 `records/search` 接口的分页逻辑与普通 records 接口不同

**建议**: 需要进一步调查飞书 API 的分页行为

### 问题 3: 状态字段存储异常

**问题描述**: 创建时设置 `status: 'completed'`，但查询显示所有任务状态都是 `pending`

**可能原因**: 飞书中状态字段的选项值不匹配，或状态转换逻辑有问题

**建议**: 检查飞书表格中"状态"字段的可选值是否与代码中的 `STATUS_REVERSE_MAP` 一致
